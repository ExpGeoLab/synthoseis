# SynToSeis — генератор синтетических сейсмических данных

## Тезисы для доклада

### 1. Назначение инструмента

- **SynToSeis** — инструмент для генерации синтетических 3D сейсмических данных и меток для обучения нейросетей
- Решает проблему нехватки размеченных данных в сейсморазведке
- Публикация: *"Synthetic seismic data for training deep learning networks"* (Interpretation, 2022)

### 2. Ключевые возможности

- Генерация реалистичных сейсмических кубов с геологическими структурами
- Настраиваемая геометрия: горизонты, сбросы, ловушки, соляные тела, фены
- Несколько типов заполнения: brine, oil, gas
- Расчёт упругих свойств (Vp, Vs, Rho) по моделям rock physics
- Применение фильтрации (Butterworth bandpass) и шума
- Поддержка угловых сумм (near, mid, far)

### 3. Архитектура конвейера

```
Параметры → Глубинные карты → Фации → Геомодели → Сбросы →
Ловушки → Упругие свойства → Сейсмические данные → Вывод
```

**8 этапов обработки:**
1. Загрузка конфигурации из JSON
2. Построение ненарушенных глубинных карт
3. Создание фациального массива (Markov chain)
4. Построение геомоделей
5. Применение сбросов
6. Детекция и классификация ловушек
7. Генерация сейсмических объёмов
8. Сохранение результатов (.npy)

### 4. Параметры генерации

| Категория | Параметры |
|-----------|-----------|
| Геометрия | `thickness_min/max`, `initial_layer_stdev`, `seabed_min_depth` |
| Сбросы | `min/max_number_faults`, `dip_factor_max`, стили сбросов |
| Ловушки | Типы: simple/faulted/onlap, пороговые размеры |
| Сейсмика | `incident_angles`, `bandwidth_low/high`, SNR в dB |

### 5. Типы геологических структур

- **Горизонты** — случайная последовательность слоёв до заданной глубины
- **Сбросы** — 5 стилей: random, self_branching, stair_case, horst_graben, relay_ramp
- **Ловушки** — 3 типа: simple (4-way), faulted (3-way), onlap (стратиграфические)
- **Соляные тела** — включение солей в модель
- **Basin floor fans** — конусовидные песчаные тела

### 6. Фациальное моделирование

- Использование Markov chain для определения песок/штам
- Настраиваемая доля песка (`sand_layer_fraction`)
- Корреляция с onlap и fan структурами

### 7. Расчёт сейсмических данных

- **Упругие свойства**: Vp, Vs, Rho по моделям rock physics
- **Коэффициенты отражения**: уравнения Zoeppritz
- **Шум**: случайный, по треугольному распределению SNR
- **Фильтрация**: Butterworth bandpass с настраиваемыми частотами

### 8. Стили сбросов

| Стиль | Описание |
|-------|----------|
| random | Случайные плоскости разломов |
| self_branching | Ветвящиеся сбросы |
| stair_case | Серия субпараллельных сбросов |
| horst_graben | Чередующиеся приподнятые/опущенные блоки |
| relay_ramp | Переходная зона между сбросами |

### 9. Pipeline данных (Dataset Pipeline)

- Из SynToSeis → извлечение патчей → создание датасета
- Поддержка задач: denoise, reflection, facies, salt, interpolation
- SFM-совместимый формат (.dat float32)
- Train/validation split (настраиваемый)

### 10. Аугментация

4 метода увеличения выборки:
- **TZ Stretch** — имитация эффектов time-depth conversion
- **Uniform Stretch** — независимое растяжение по X, Y, Z
- **Flip** — горизонтальное/вертикальное отражение
- **Jitter** — добавление шума (только к входным данным)

### 11. API и интеграция

- FastAPI сервер для запуска генерации
- Веб-интерфейс (React)
- REST API для управления датасетами
- Поддержка параллельной обработки

### 12. Конфигурация

- JSON-формат для всех параметров
- Пример: `config/example.json`
- Можно добавлять собственные rock physics модели

### 13. Формат вывода

```
project_folder/seismic_timestamp/
├── seismicCubes_RFC_fullstack.npy
├── seismicCubes_RFC_near/mid/far.npy
├── lithology_timestamp.npy
├── net_to_gross_timestamp.npy
├── faulted_age_volume_timestamp.npy
└── closures_timestamp.npy
```

### 14. Преимущества

- Генерация большого объёма размеченных данных
- Контролируемая вариативность (все параметры настраиваются)
- Геологическая достоверность (реальные модели rock physics)
- Расширяемость (можно добавлять свои модели)

### 15. Применение

- Обучение нейросетей для интерпретации сейсмических данных
- Задачи: шумоподавление, определение фаций, сегментация соли, интерполяция
- Дополнение реальных данных синтетическими

### 16. Веб-интерфейс SynToSeis UI

Современный веб-интерфейс на React + TypeScript + Tailwind обеспечивает удобную работу с инструментом.

#### Dashboard — центр управления

- **Обзорная панель** с карточками статистики: общее число запусков, завершённые, выполняемые, неудавшиеся
- **Быстрый доступ** к последним запускам и датасетам
- **Автообновление** данных каждые 5 секунд
- **Один клик** для создания нового запуска

#### Runs — управление генерацией

- **Список запусков** со статусами: pending, running, completed, failed, cancelled
- **Детальная страница** каждого запуска:
  - Прогресс-бар с текущим этапом
  - Живой вывод консоли (логи Python-процесса в реальном времени)
  - Краткое описание конфигурации
  - QC-изображения (графики качества)
- **Отмена** выполняющихся задач
- **Автообновление** каждые 3 секунды для запущенных задач

#### Configuration Editor — визуальный редактор параметров

- **7 тематических секций** с сворачиваемыми блоками:
  - Model Configuration — базовые параметры модели
  - Layer Parameters — толщина и глубина слоёв
  - Seismic Parameters — параметры сигнала и фильтрации
  - Fault Configuration — структурные разломы
  - Closure/Trap Settings — детекция углеводородных ловушек
  - Geological Features — соли, каналы, фены
  - Output & QC — настройки вывода

- **Интерактивные подсказки** (tooltips) для каждого параметра:
  - Название параметра
  - Подробное описание назначения
  - Единицы измерения
  - Диапазон допустимых значений

- **Умные виджеты ввода**:
  - Min/Max слайдеры для диапазонов (depth, stdev, bandwidth)
  - 3 поля для угловых сумм (Near/Mid/Far)
  - 3 поля для SNR (Left/Mode/Right)
  - X/Y/Z размеры куба
  - Toggle-переключатели для булевых параметров
  - Вложенные объекты (sand_layer_fraction)

- **Импорт/Экспорт** конфигураций в JSON
- **Валидация** значений по умолчанию

#### Datasets — создание датасетов для обучения

- **Выбор типа задачи** (task type):
  - Denoise — шумоподавление
  - Facies — классификация фаций
  - Salt — сегментация соляных тел
  - Interpolation — восстановление пропущенных трасс
  - Reflection — оценка отражательной способности

- **Выбор источников** — завершённые запуски SynToSeis
- **Настройка патчей**:
  - Размеры (X, Y, Z)
  - Режим извлечения (random, grid)
  - Количество патчей на объём

- **Аугментация** с наглядными настройками:
  - Toggle для включения
  - Выбор методов (TZ Stretch, Uniform Stretch, Flip, Jitter)
  - Конфигурация для каждого метода (направление флипа, уровень шума, распределение)
  - Визуальный прогноз результата

- **Train/Validation split** со слайдерами
- **Нормализация** (Standard Z-score или Min-Max)
- **Статистика** по созданным датасетам

#### Rock Physics — настройка моделей rock properties

- **4 типа пород**: Shale, Brine Sand, Oil Sand, Gas Sand
- **3 свойства** на тип: Vp, Vs, Rho как функции глубины
- **Полиномиальные тренды**: `value = a·z³ + b·z² + c·z + d`
- **Сохранение/загрузка** конфигураций

#### Wavelets — генерация сейсмических вейвлетов

- **Типы вейвлетов**: Ricker (Mexican Hat), Ormsby, Klauder
- **Интерактивный canvas** с визуализацией амплитуды
- **Настройка параметров**: частота, rate дискретизации, длительность, полярность
- **Мгновенный просмотр** результата

#### Системные настройки

- **Автообнаружение** historic runs (созданных вне веб-интерфейса)
- **Настройка путей** поиска (work_folder, project_folder)
- **Валидация путей** с индикацией существования
